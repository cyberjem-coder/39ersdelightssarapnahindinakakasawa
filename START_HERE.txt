MENU HTTP 502 RELIABILITY UPDATE
The mobile-menu function now retries short Blobs read failures and logs a mobile-menu incident ID. The customer QR page retries transient 502/503/504 errors, retains its last successfully loaded public menu on that phone, and reconnects automatically every 60 seconds. The cached menu is for display only: a fresh server check is still required at checkout, and failed checks prevent order submission. If errors continue, inspect Netlify Function logs for [mobile-menu] and the incident ID. Do not clear Blobs or reset cashier authorization.
